## Priority Issues
1. [P1] Dead/decorative controls everywhere (topbar search, dashboard Filter, Kanban more, employee Filter/Edit, Records Export/Print, Reports Export/calendar/tune, fake backdrop on Create Task). Fix: remove. Command: distill.
2. [P1] Type too small, all-caps, low contrast for older users. Fix: 16px base, 14px min, sentence case, 4.5:1, one font. Command: typeset.
3. [P1] Inconsistent/wrong status vocabulary (Rejected/Returned/Returned for Correction; For Review styled as In Progress; swapped Employee/Task Assignee headers in Tasks/Index; Department/Division/OPD). Fix: one status glossary + colour map. Command: clarify.
4. [P1] Keyboard/SR blockers (div profile trigger hides Sign Out; no focus styles; unlabeled icon buttons; no h1; unlinked Review label; nested main). Command: audit/harden.
5. [P2] Submit Proof and Review lack context and safeguards (no description, no return remarks, no preview, one-click Approve). Command: harden.
Also: replace the employee Gantt/Kanban/Top Performers dashboard with a "Needs your action" list (shape).
