DTI OneLink — System / Level 0 DFD

First-level decomposition: five numbered processes, the three user entities plus the outbound email service, and the four data stores each process reads from or writes to.

Revision notes (vs. v1): every request/response pair is now drawn as two separate single-direction arrows instead of one bidirectional line; Processes 1.0–3.0 and 5.0 each include an explicit request-in flow from the entities that use them (not just the response out); the two former direct process-to-process triggers (2.0→4.0, 3.0→4.0) are removed — 2.0 and 3.0 now write pending-event records into D4, and 4.0 reads D4 to decide what to send, so no process connects directly to another process.

Process descriptions

IDProcessDescription
1.0Authenticate & Manage AccountsValidates login credentials, enforces role-based access, and lets authorized users create, update, or deactivate accounts.
2.0Manage TasksHandles task creation, assignment, status updates, proof-of-completion submission, and supervisor review/validation. Writes a pending-event record to D4 when a task becomes due, overdue, or submitted for review.
3.0Manage RecordsHandles records classification, indexing, retrieval, and retention/disposal monitoring against NAP guidelines. Writes a pending-event record to D4 when a record nears its retention review date.
4.0Send NotificationsReads pending-event records from D4 and generates in-app and outbound email alerts; writes a log entry back to D4 for each notification sent.
5.0Generate Dashboard & ReportsOn a view request from any entity, reads current task and records data from D2 and D3 and returns a role-scoped dashboard or exportable report.
